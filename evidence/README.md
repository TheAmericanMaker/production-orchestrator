# Executed Spike Evidence

These reports were generated by real Strands 1.51.0 executions against the synthetic shop fixture.

- [`rejection.json`](rejection.json): real interrupt resumed with rejection; domain state stayed at revision 1.
- [`approval.json`](approval.json): independent real interrupt resumed with approval; exact proposal advanced state to revision 2.

Each report includes:

- Provider/model and SDK version
- Interrupt ID, name, proposal hash, and reviewed changes
- Pre-interrupt and final domain digests
- Final schedule and procurement tasks
- `AgentResult` tool metrics
- Persistent application audit events
- Eight machine-evaluated workflow checks
- Honest submission-gate status

The reports use the documented Ollama fallback because the local AWS credential chain is unavailable. `workflow_passed: true` means the Strands orchestration and safety loop passed. `submission_gate_passed: false` means Bedrock evidence is still required.

Runtime databases and `FileSessionManager` artifacts are intentionally ignored because they contain transient conversation state. Their existence and file counts are captured by the evidence checks.
